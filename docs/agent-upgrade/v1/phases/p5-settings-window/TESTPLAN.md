# P5 测试计划：设置独立窗口

### TC-P5-1：设置入口打开独立窗口
- 对应验收：AC-P5-1
- 步骤：点击主窗口设置入口。
- 期望：打开独立设置窗口。

### TC-P5-2：防止重复设置窗口
- 对应验收：AC-P5-2
- 步骤：连续多次点击设置入口。
- 期望：聚焦已有设置窗口，不创建多个重复窗口。

### TC-P5-3：设置保存通知主窗口
- 对应验收：AC-P5-3
- 步骤：修改设置并保存。
- 期望：主窗口收到 `settings:updated` 并刷新相关状态。

### TC-P5-4：关闭设置窗口不影响聊天
- 对应验收：AC-P5-4
- 步骤：打开设置窗口后关闭，再在主窗口发送消息。
- 期望：主窗口可继续聊天。

### TC-P5-5：设置窗口包含 Agent 相关配置
- 对应验收：AC-P5-5
- 步骤：打开设置窗口查看配置项。
- 期望：可管理 Agent 模式、工作区、Skill 相关配置。
