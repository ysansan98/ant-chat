# P2 测试计划：Agent Runtime 与审批

### TC-P2-1：简单问题不显示进度 UI
- 对应验收：AC-P2-1
- 步骤：输入一个简单事实问题。
- 期望：走普通聊天流程，不出现输入框上方进度列表。

### TC-P2-2：复杂任务触发 Agent task
- 对应验收：AC-P2-2
- 步骤：输入“检查当前项目并总结需要修改的地方”。
- 期望：调用 `startTask`，进入 Agent task。

### TC-P2-3：复杂任务显示进度列表
- 对应验收：AC-P2-3
- 步骤：触发复杂任务。
- 期望：输入框上方出现轻量进度列表。

### TC-P2-4：进度状态完整
- 对应验收：AC-P2-4
- 步骤：观察任务推进过程。
- 期望：列表项状态包含已完成、进行中、未开始。

### TC-P2-5：取消运行中 task
- 对应验收：AC-P2-5
- 步骤：复杂任务运行中点击取消。
- 期望：task 停止，UI 显示取消状态，不再继续执行。

### TC-P2-6：预算超限停止
- 对应验收：AC-P2-6
- 步骤：设置很小的 maxSteps 或 maxDurationMs 后触发复杂任务。
- 期望：task 停止并显示预算超限错误。

### TC-P2-7：hybrid 下 L0 自动执行
- 对应验收：AC-P2-7
- 步骤：hybrid 下触发只读工具。
- 期望：自动执行，无审批。

### TC-P2-8：hybrid 下 L1/L2 触发审批
- 对应验收：AC-P2-8
- 步骤：hybrid 下触发写入或 bash 动作。
- 期望：出现审批 UI，动作暂停。

### TC-P2-9：审批拒绝不执行
- 对应验收：AC-P2-9
- 步骤：对待审批动作点击拒绝。
- 期望：目标动作不执行，文件系统无非预期变更。

### TC-P2-10：full_managed 自动推进与硬阻断
- 对应验收：AC-P2-10
- 步骤：full_managed 下分别触发安全动作和工作区外写入。
- 期望：安全动作自动推进；工作区外写入仍被阻止。
