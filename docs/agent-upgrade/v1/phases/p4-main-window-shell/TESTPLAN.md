# P4 测试计划：主窗口 UI Shell

### TC-P4-1：主窗口布局完整

- 对应验收：AC-P4-1
- 步骤：启动应用查看主窗口。
- 期望：包含工作区入口、对话列表、工具区、聊天区。

### TC-P4-2：对话列表按工作区过滤

- 对应验收：AC-P4-2
- 步骤：在工作区 A/B 分别创建会话并切换工作区。
- 期望：只显示当前工作区会话。

### TC-P4-3：工具区展示能力状态

- 对应验收：AC-P4-3
- 步骤：打开工具区。
- 期望：能看到 Native Tools 和 Skill 状态。

### TC-P4-4：新 Shell 中聊天正常

- 对应验收：AC-P4-4
- 步骤：在新布局中发送普通消息。
- 期望：聊天区正常流式显示回复。

### TC-P4-5：进度列表位置正确

- 对应验收：AC-P4-5
- 步骤：在新 Shell 中触发复杂任务。
- 期望：进度列表显示在输入框上方。
