# Triage Labels

技能使用五个标准 triage 角色。此文件将这些角色映射到本仓库 Issue tracker 中实际使用的标签字符串。

| Skill 中的角色 | 本仓库标签 | 含义 |
| -------------- | ---------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 Issue |
| `needs-info` | `needs-info` | 等待报告人补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确规格，AI 可接手处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会被处理 |

当技能提到某个角色（例如 "apply the AFK-ready triage label"），使用此表中对应的标签字符串。

如需调整标签名称，直接编辑右列即可。
